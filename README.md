# Customer Shopping Behavior Analysis Dashboard

This project analyzes customer shopping behavior using SQL, Python, and Power BI. The objective is to uncover purchasing trends, customer preferences, and key business insights from retail transaction data.

The project includes:

* Data cleaning and preprocessing using Python
* Exploratory Data Analysis (EDA)
* SQL queries for business insights
* Interactive Power BI dashboard
* KPI tracking and visual analytics

## Tools Used

* Python (Pandas, NumPy, Matplotlib)
* MySQL
* Power BI
* Git & GitHub

## Key Insights

* Identified top-performing products and categories
* Analyzed customer purchasing patterns
* Evaluated sales and profit trends
* Created interactive dashboards for business decision-making
